An entry for the make.fun bounty "One Letter for Your Day". The brief asks for exactly one character, a letter A to Z and nothing else, with a word behind the letter describing the entrant's day.

My letter is **G**, standing for the word **Grinding**: Monday 23 November 2026 was spent grinding nonstop through bug-bounty sweeps and make.fun entries, one task after another from morning to late night. That is the honest word for this working day.

## Run it

```bash
python3 main.py
```

This writes exactly one character, `G`, to `/output/entry.txt` -- no trailing newline, no other output in the file. Standard library only, no dependencies.
